Phần 3: Architecture & PoC

Kiến trúc Tổng thể Modular Monolith & Tech Stack

Công nghệ Lựa chọn

  • Frontend: React.js / Next.js + HTML5 Canvas API.
  • Backend: NestJS (Modular Monolith) + TypeScript.
  • Storage Vault: MinIO Object Storage (Mã hóa AES-256).
  • Database & Queue: PostgreSQL 16 + Redis 7 & BullMQ.
  • OCR Engine: Tesseract OCR (`vie`).

Ưu điểm Kiến trúc Modular Monolith

  • Triển khai gọn nhẹ qua 01 gói Docker Container.
  • Tận dụng $100\%$ hạ tầng MinIO/NestJS sẵn có của nhóm.
  • Tách luồng OCR ngầm qua Redis Queue, không nghẽn Web API.
Phần 3: Architecture & PoC

Mô hình Mã hóa Kho MinIO & Secure Stream

1. Lưu kho Mã hóa MinIO Vault

  • Tài liệu scan sau khi duyệt được cắt nhỏ thành Chunks/Pages.
  • Mã hóa thuật toán AES-256-GCM trước khi ghi vào MinIO.
  • Tuyệt đối không lưu file PDF thô nguyên bản trên máy chủ.

2. Secure Memory Streaming

  • Không cấp Presigned URL tĩnh của MinIO ra ngoài Client.
  • Backend cấp Signed Token (TTL 30s) và đẩy luồng byte mã hóa qua WebSockets/API về RAM Client.

Phần 4: Development Method

Mô hình Lai Hybrid Waterfall-Scrum

1. Khung Thác nước (Waterfall)

Áp dụng ở Giai đoạn Khởi động/Kiến trúc (Sprint 1) và Nghiệm thu UAT/Đóng gói bàn giao (Sprint 5) để kiểm soát mốc tiến độ hợp đồng SOW.

2. Lõi Agile / Scrum

Áp dụng ở 3 Sprint cốt lõi (Sprints 2, 3, 4) chu kỳ 2 tuần/Sprint. 6 sinh viên phát triển cuốn chiếu 16 PBIs, họp Daily Standup & Demo cuối mỗi Sprint.

Phần 4: Development Method

Ứng dụng Trợ lý AI Coding & Tích hợp Mã nguồn

1. AI Senior Mentor

Antigravity IDE + Google AI Pro hỗ trợ sinh code boilerplate, gợi ý thuật toán Canvas & viết Unit Test suite. Tăng $38.5\%$ năng suất ($1\text{ SP} \approx 8\text{h}$).

2. Git Branching Strategy

Mỗi PBI phát triển trên 1 Feature Branch riêng. Pull Request bắt buộc qua Peer Review của Tech Lead (SV-1) & AI Security scan.

3. CI/CD & Docker

Tự động chạy Unit Test suite và đóng gói Docker Image đẩy lên máy chủ Staging thử nghiệm.
